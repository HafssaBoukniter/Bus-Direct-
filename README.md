# BusDirect – Gestion des réservations

## Présentation

BusDirect est une application web qui permet de gérer les réservations de sièges pour le trajet **Safi → Marrakech**.

L’objectif est de faciliter la réservation, la modification et la suppression des places grâce à une interface simple et interactive.

## Fonctionnalités

- Affichage du plan des 20 sièges.
- Réservation d’une place avec attribution automatique si aucun siège n’est choisi.
- Modification du nom du passager et de son siège.
- Suppression d’une réservation.
- Mise à jour des places disponibles et de la recette totale.
- Sauvegarde des données avec `localStorage`.
- Validation des formulaires et affichage des messages.
- Interface responsive adaptée aux différents écrans.

### Bonus

- Recherche d’un passager.
- Sélection d’un siège en cliquant dessus.
- Drag & Drop pour déplacer une réservation.
- Affichage des billets réservés.

## Technologies utilisées

- Tailwind CSS
- JavaScript

3. Lancer le fichier `index.html` dans le navigateur ou utiliser Live Server.

## Tarif

Le prix d’une place est fixé à **80 DH**.

La recette totale est calculée selon le nombre de sièges occupés.
